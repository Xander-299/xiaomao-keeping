# v0.8.13 发布说明

**发布时间**：2026-11-19 · **版本** `0.8.13+2013` · 三个 ABI 包（arm64-v8a / armeabi-v7a / x86_64）

这一版主要是**自动记账的「看得见」**：以前「通知使用权明明开着，却一条都记不上」时，
App 只会说「从未收到过支付通知」，让人以为是没付款。现在它会告诉你**断在哪一段**，
并且在系统把监听服务掉了的时候**自己尝试重绑**。

---

## 一、自动记账：断点终于能看见了

如果你遇到过「设置里开着，但微信 / 支付宝的支付一条都没记上」，这一版针对的就是它。

以前的问题：系统没把监听服务绑上时，补抓会失败，但失败被折成了「没有可补的通知」，
页面于是提示「支付后打开本 App 一次就会补记上」—— 而那条路当时根本不通。

现在：

- **诊断块新增「补抓通道」一行**：正常 / 不通；不通时写明「已尝试重绑 N 次未成功」；
- **提示语直接指向动作**：把「通知使用权」关掉再打开一次，仍不行就重启手机；
- 不再对你说「打开 App 一次就能补上」，除非补抓通道确实活着；
- 监听服务断开时**自动请求系统重绑**；从未绑定过时，打开 App 也会主动请求一次（60 秒最多一次）。

## 二、顺手修掉的三个真实缺陷

- **补抓回写的通知被裁掉**：队列超过 500 条时，被丢的恰好是「刚回写、还没入账」的那批 → 改为优先保留；
- **只带副标题的通知被当成空**：这类通知以前直接被丢弃并计入「空文案」，排查时会被误读成「通知是空的」；
- **隐私说明写错了**：页面上「本 App 没有申请网络权限」自 v0.8.7（云同步）起就不成立 →
  改为「默认只存本机，只有你自己打开云同步 / 云备份时才会加密上传到你的账号」。

## 三、分类预算的选分类弹层

点「添加分类预算」后的选择分类弹层不再几乎铺满整屏：最高占屏幕 60%，内容多了在弹层内滚动，
一级 / 二级分类的行也压紧了一档。

## 四、一个重要提醒（和这一版无关，但会让你以为它坏了）

**装了并列包（QA 包）之后，正式包会「静默失聪」。**「通知使用权」在系统里按包名记，
但同一时间系统只绑一个 —— QA 包占住之后，正式包的开关还显示「已开启」，实际不再收到任何通知。

- 用过 QA 包 / 调试包后，去系统设置里把**正式包**的「通知使用权」关掉再打开一次；
- 或者干脆卸载 QA 包（`com.teacodeman.yanxin.qa`）；
- 判断方法：本版 `/autobook` 页「补抓通道」显示「不通（系统未绑定监听服务）」。

## 五、数据与兼容

- **没有数据库结构变化**（仍是 schema v7），账本、预算、同步都不受影响；
- 三个包同一把签名，可直接覆盖安装 v0.8.12，数据保留；
- 覆盖安装后「我的」页角标应显示 **v0.8.13**。

## 六、装哪个包

| 你的手机 | 下哪个 |
|---|---|
| 绝大多数近几年的 Android（arm64） | **arm64-v8a** |
| 很老的 32 位机器 | armeabi-v7a |
| 模拟器 / x86 平板 | x86_64 |

校验下载完整性：对照 `SHA256SUMS.txt`；签名指纹与自证方式见 `VERIFY.md`。
