# v0.8.7 发布说明

**发布时间**：2026-11-14 · **版本** `0.8.7+2007` · 三个 ABI 包（arm64-v8a / armeabi-v7a / x86_64）

这一版把**云同步**真正接进了 App：登录一个账号，就能把账本备份到云端；换手机后登录同一个账号，一键恢复。

> 默认**关闭**。不登录、不开开关，App 不会发出任何请求。

---

## 一、账号：邮箱验证码登录

- 「设置 → 数据 → 云同步」→ 输入邮箱 → 收 6 位验证码 → 登录；
- 登录态存在 **Android Keystore**（AES/GCM 加密），**杀进程、重启手机都不掉**；
- 「退出登录」本地优先：即使服务器暂时连不上，也一定退得掉；
- 「注销账号」= **云端硬删**：账户行、refresh token、备份文件全部物理删除；注销后旧的 access token 立即失效（服务端已修）。

## 二、云备份：手动上传 + 换机恢复

- 「立即备份到云端」：把**当前账本**的完整备份（账本 / 账户 / 分类 / 流水 / 预算 + 外观与首页布局）传到云端；
  格式与「数据导出 → 备份 JSON」**完全相同**，两边可以互相恢复。
- 「从云端恢复」：合并进当前账本，**按流水指纹去重**，不会删除现有数据；
  备份里带外观 / 布局时会先问你要不要一并恢复。
- 页面显示「上次备份：时间 · 大小」；云端没有备份时明确提示。

## 三、边界与限制（请先看）

- **本版不是实时同步**：没有自动上传、没有双向合并、没有冲突处理（那是 P6.4）。
  日常记账仍只在本机；换机/刷机前记得手动点一次「立即备份到云端」。
- 备份上限 **20 MB**；云端只保留最近几份快照。
- 登录验证码由**个人邮箱**发出，可能进垃圾箱；收不到先看垃圾箱。
- 云功能需要联网；不登录 / 关开关时**一个字节都不发**，全链路 HTTPS + 域名白名单。
- 正式包带 `INTERNET` 权限（只为云同步存在）；`ACCESS_NETWORK_STATE` 仍被移除。
- 服务端只记「条数 / 时间 / 错误码」，**不记金额与备注正文**；注销即硬删。

## 四、装哪个包

| 你的手机 | 下哪个 |
|---|---|
| 绝大多数近几年的 Android（arm64） | **arm64-v8a** |
| 很老的 32 位机器 | armeabi-v7a |
| 模拟器 / x86 平板 | x86_64 |

三个包**同一把签名**，可直接覆盖安装 v0.8.6，账本数据保留。
覆盖安装后「我的」页角标应显示 **v0.8.7**。

## 五、已知问题

- 云同步目前只支持「备份 / 恢复」，不支持多设备实时合并；
- 邮箱验证码走个人 126 邮箱 SMTP，量大时可能触发发信限制（个人使用足够）；
- 云备份入口只覆盖**当前账本**，多账本需要逐个切换后备份。
