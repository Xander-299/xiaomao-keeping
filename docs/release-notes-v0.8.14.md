# v0.8.14 发布说明

**发布时间**：2026-11-19 · **版本** `0.8.14+2014` · 三个 ABI 包（arm64-v8a / armeabi-v7a / x86_64）

一个小版本，修的是**多账本用户**才会碰到的坑，另有两处内部清理。没有数据库结构变化。

---

## 一、切账本后「最近一次自动记账」不再串账本

自动记账的「最近一次」记录是**全机共用一份**（只留最近 3 批）。以前切到另一个账本后，
`/autobook` 页仍显示**上一个账本**那一批：笔数、合计都对，但点「撤销」一定得到
「这批已撤销或不复存在」—— 因为那批流水根本不在当前账本里。

现在按当前账本取：切过去看不到别的账本的批次，撤销按钮指向的就是你自己的账。

> 单账本用户完全无感；升级后旧版本留下的批次（没有账本标记）不再显示，等下一次自动记账就会出现。

## 二、诊断文案订正

`/autobook` 的诊断里「组摘要」那一项的说明还写着旧结论（「留着会把同一笔记两遍」）。
真机取证早就推翻了它：微信支付通知上的 `[N条]` 只是系统显示层加的前缀，按它过滤会**漏记**。
现在的判定只认系统标志，注释也随之改准 —— 不影响行为，只是别再让下一个人被注释带偏。

## 三、内部清理

- 删掉一段从未被调用的「取消补抓守护」代码（死代码）；
- 补了 3 个用例盯住「批次按账本取」这条规则。

## 四、数据与兼容

- **没有数据库结构变化**（仍是 schema v7），账本、预算、同步都不受影响；
- 三个包同一把签名，可直接覆盖安装 v0.8.13，数据保留；
- 覆盖安装后「我的」页角标应显示 **v0.8.14**。

## 五、装哪个包

| 你的手机 | 下哪个 |
|---|---|
| 绝大多数近几年的 Android（arm64） | **arm64-v8a** |
| 很老的 32 位机器 | armeabi-v7a |
| 模拟器 / x86 平板 | x86_64 |

校验下载完整性：对照 `SHA256SUMS.txt`；签名指纹与自证方式见 `VERIFY.md`。
