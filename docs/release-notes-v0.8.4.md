# v0.8.4 发布说明

**发布时间**：2026-11-13 · **版本** `0.8.4+2004` · 三个 ABI 包（arm64-v8a / armeabi-v7a / x86_64）

---

## ⚠️ 先说一件会影响你预期的事

因为**云同步立项**（还没上线，只是先铺地基），**从这个版本起正式包带 `INTERNET` 权限**。
之前那句「正式包没有网络权限」不再成立，取而代之的承诺是：

- **默认不联网**：不登录就一条请求都不发（`CloudSyncGate` 卡在请求入口，不依赖调用方自觉）；
- **只走 HTTPS**：全局 `cleartextTrafficPermitted="false"`，明文请求在系统层就被拒；
- **只连白名单域名**：服务器地址写死在代码里，不从服务端下发；
- 不卖数据、不做行为画像、没有广告与埋点 —— **这条没变**。

本版的 App **还没有任何同步功能**，`server/` 只是源码。真要生效得等你部署。

## 这一版带来了什么

### 设置与外观

- **设置 → 主题色与外观**：外观模式与主题色拆成两个子页，卡片风格跟「首页布局」一致。
- **默认外观 = 浅色，默认主题色 = 琥珀**（琥珀排到色板第一位）。

### 首页布局

- 改成**树形**：子项只在展开父模块后出现，字号更小、开关更小，父级仍可拖拽排序。
- 模块参数不再只有开关：
  - **本月账单** → 显示条数（全部 / 10 / 20）
  - **本月预算** → 副行口径（还剩 / 已花）
  - **记一笔 / 问一句** → 示例问题条数（1–3）

### 备份与换机

- 导出的 JSON 备份现在可以**直接被「导入账单」识别**：账本、账户、分类、流水、预算整体恢复，
  重复导入按指纹去重，不会翻倍。
- 备份里**带上外观与首页布局**。换新手机导入时，会问你一句：
  **一并恢复**（默认）还是 **只恢复账本**。

### 导入体验

- 「跳过」拆成两类：`跳过（退款/失败/无效）` 和 `不计收支（转账/提现等）N 笔 · ¥X`。
  微信/支付宝账单**头部**的收支合计是含转账提现的，本 App 不计入 —— 报告里直接说明差额来自哪里，
  再也不会看起来像「丢了 78 块」。
- 分类规则修正：
  - `手机充值-中国联通` → **通讯**（原来错进「居住」）
  - `发给~青年旅社` → **旅行**（原来落「其他」）
  - `抖音生活服务` → **娱乐**（原来落「其他」）
  - 还修了一个更要命的：规则里有三个分类名跟预置分类对不上（`人情`/`理财`/`红包`），
    导致**礼金、基金、红包这些词导入时全落「其他」**。现在对齐成 `人情社交`/`投资收益`/`红包礼金`。

### 可靠性

清掉了 5 条 P3 遗留：

1. 导入指纹并发竞争（并发导入不再整批失败，改为「已存在」）；
2. 删除不校验受影响行数（这行已被别处删掉时，改口说「这笔已经不在了」，不给撤销）；
3. 自动记账撤销失败不再静默（原因写进 `/autobook` 的诊断块）；
4. 分类 `undelete()` 全程事务化；
5. 换账本后日历不再串数据。

## 装哪个包

| 你的手机 | 下哪个 |
|---|---|
| 绝大多数近几年的 Android（arm64） | **arm64-v8a** |
| 很老的 32 位机器 | armeabi-v7a |
| 模拟器 / x86 平板 | x86_64 |

三个包**同一把签名**，可以直接覆盖安装旧版本，账本数据保留。
