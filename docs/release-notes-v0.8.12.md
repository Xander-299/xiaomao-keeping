# v0.8.12 发布说明

**发布时间**：2026-11-17 · **版本** `0.8.12+2012` · 三个 ABI 包（arm64-v8a / armeabi-v7a / x86_64）

这一版补上了从 v0.7 就挂账的 **分类预算**：总预算之外，可以给「餐饮」「交通」这类一级分类、
甚至「餐饮 · 早餐」这样的二级分类单独设额度。

---

## 一、分类预算怎么用

- 首页那条预算条**点一下**进「预算」页：上半是本月总预算，下半是分类预算列表；
- 「添加分类预算」→ 选分类 → 输金额；
- 每行显示「已花 / 额度」+ 进度条，超支标红并写「已超支 ¥xx」；
- 「沿用上月」一键把上个月设过的分类预算复制过来（**已有的不覆盖**）。

## 二、两条口径，先看懂再设

- **一级分类的「已花」包含它的全部子分类**：所以「餐饮 ¥800/¥1200」里已经算进了
  「早餐」「午餐」的花销，页面标题旁写了「一级含子分类」；
- **总预算与分类预算各算各的**：总预算不会自动等于分类之和，两者互不影响。

## 三、另外两处能看到它

- **首页预算条**：有分类超支时，副行会点名「餐饮超支 ¥120」；多类超支写「餐饮等 2 类超支」；
- **统计页**：支出分类排行每条下面加一行「预算 ¥800 · 已用 72%」，超支转红。

## 四、数据与兼容

- 数据库升级到 **schema v7**：只给预算加了一列 + 换了一条唯一索引，既有账本与总预算**不受影响**；
- 备份 JSON 里 `budgets` 多了可选字段 `categoryId`；
  **用旧版本 App 恢复新备份时，分类预算会退化成总预算**（同月只能留一条），属已知限制；
- 云同步无需服务端改动，预算行照常上行下行。

## 五、装哪个包

| 你的手机 | 下哪个 |
|---|---|
| 绝大多数近几年的 Android（arm64） | **arm64-v8a** |
| 很老的 32 位机器 | armeabi-v7a |
| 模拟器 / x86 平板 | x86_64 |

三个包**同一把签名**，可直接覆盖安装 v0.8.11，账本数据保留。
覆盖安装后「我的」页角标应显示 **v0.8.12**。

## 六、已知限制

- 分类预算只到二级（分类树目前两层）；
- 不做跨月自动延续，需要「沿用上月」手动复制；
- 统计页只在「支出」方向显示预算叠加（收入没有预算概念）；
- 分类归档后，它的预算会从可编辑列表里消失（历史月仍能看到名字与额度）。
