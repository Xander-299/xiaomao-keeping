# v0.8.17 发布说明

**发布时间**：2026-11-24 · **版本** `0.8.17+2017` · 三个 ABI 包（arm64-v8a / armeabi-v7a / x86_64）

一个小修：**在系统设置里改完省电策略，回到 App 那行状态不跟着变**。没有新功能。

---

## 修了什么

`我的 → 自动记账 → 后台常驻` 那两行（「省电优化」「常驻服务」）只在**打开页面时**读一次系统状态。
你按提示跳到系统设置、把我们设成「无限制」再回来，页面还是显示「未忽略」——看着像没生效。

现在从系统设置返回 App 时，这两行会**自动重读**：设成「无限制」回来就是「已忽略」，
常驻服务被杀掉过也会显示真实状态。不用再手动退出去重进。

## 要不要更新

- 正在用「后台常驻」的：**建议更新**（否则状态显示会误导你）；
- 没开常驻的：更新与否都不影响记账，等你需要时再开。

## 数据与兼容

- 无数据库结构变化（仍 schema v7），可直接覆盖安装 v0.8.16，数据保留；
- 覆盖后「我的」页角标应显示 **v0.8.17**。
- 更新完如果「通知使用权」显示开着但 `诊断` 里「监听服务 = 未绑定」，
  按老办法把「通知使用权」关掉再打开一次（国产 ROM 的老问题）。

## 装哪个包

| 你的手机 | 下哪个 |
|---|---|
| 绝大多数近几年的 Android（arm64） | **arm64-v8a** |
| 很老的 32 位机器 | armeabi-v7a |
| 模拟器 / x86 平板 | x86_64 |
