# v0.8.6 发布说明

**发布时间**：2026-11-13 · **版本** `0.8.6+2006` · 三个 ABI 包（arm64-v8a / armeabi-v7a / x86_64）

这一版只干一件事：**让「导出」和「导入」真正闭环** —— 你自己导出的数据，现在能导回来了。

---

## 之前为什么导不回来（三个独立原因）

| 现象 | 真正原因 |
|---|---|
| 导出 **JSON 备份** → 导入说「无法识别」 | 识别逻辑只在文件**前 2 KB** 里找特征关键字。备份的字段顺序是「版本 → 书 → 账户 → 分类 → 流水」，分类一多，流水那个关键字就被挤到 2 KB 之后（实测：51 个分类时在 20 KB 处）。**分类越多的用户越必踩**，反而只含几条数据的小备份能过 |
| 导出 JSON 后在**文件选择器里找不到** | 系统选择器的类型白名单没放行 `.json`，备份文件是灰的/看不见 |
| 导出 **CSV** → 导入说「无法识别」 | 导入只认微信 / 支付宝两套表头，没有「小耄记账 CSV」这一套 |

## 现在

- **CSV**：导入能识别自己导出的格式，并且**分类 / 账户 / 备注原样带回来**（不再被自动分类规则重新猜一遍）；
  账户按名字复用，缺了才新建；`转账` 行按「不计收支」跳过并在报告里列出笔数与金额。
- **JSON 备份**：识别窗口从 2 KB 放宽到 64 KB，并先判断「是不是 JSON 对象」。
  你之前那份备份现在可以直接导回来（整本恢复：账本 / 账户 / 分类 / 流水 / 预算，可选带外观与布局）。
- **不会重复记账**：CSV 导出末尾新增 `流水ID` 列 —— 同一份文件反复导、或把导出文件**导回原账本**，
  都是 `0 新增 / N 重复`。老文件（没有这一列）照样能导，按指纹去重。

## 顺带

- 导入页的说明补上了「小耄记账：自己导出的备份（.json，整本恢复）或流水（.csv）」；
- 预览页「识别为「…」账单」不再把所有非微信文件都显示成「支付宝」。

---

## 装哪个包

| 你的手机 | 下哪个 |
|---|---|
| 绝大多数近几年的 Android（arm64） | **arm64-v8a** |
| 很老的 32 位机器 | armeabi-v7a |
| 模拟器 / x86 平板 | x86_64 |

三个包**同一把签名**，可直接覆盖安装旧版本，账本数据保留。

## 已知问题

- 云同步**尚未可用**：服务端源码与部署文档在仓库 `server/`，App 端还没接。
- 正式包自 v0.8.4 起带 `INTERNET` 权限：**不登录就不发请求**，全链路禁明文、只连白名单域名。
