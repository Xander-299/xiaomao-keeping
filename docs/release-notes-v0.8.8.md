# v0.8.8 发布说明

**发布时间**：2026-11-14 · **版本** `0.8.8+2008` · 三个 ABI 包（arm64-v8a / armeabi-v7a / x86_64）

这一版主要是「手感」和「界面」：**日历翻月改成跟手翻页**，窗口里的三处页面做了统一收口，
另外给云同步补了第一版**账本双向同步**（实验）。

---

## 一、日历翻月：跟手翻页

- 手指拖多少，月历就翻多少，**可以停在半路**（松手前不撒手，页面就一直停在你拖到的位置）；
- 松手时按两件事决定去向：**拖过半屏**，或者**顺方向甩得够快**（> 420 px/s）→ 翻过去；否则 220 ms 弹回；
- 已经是**最新一个月**时再往左拖，只给一点点阻尼（最多 1/3 屏），松手必回弹 —— 不会拖出一片空白；
- 拖动过程中，相邻月份的**日标注和月汇总**就已经准备好了，不会出现「滑到一半是空网格」；
- 月历网格固定 **6 行**（多出来的格子画相邻月的灰日期），两页同高 —— 翻页时下面的账单区不会被顶动；
- 修掉浅色模式下翻页接缝上的一条灰线。

> 「月份选择」页（点标题进的那个）仍是整屏滑入，还不能拖 —— 它是另一个路由，后续再改。

## 二、账本同步（实验）：两台手机手动合并

「设置 → 数据 → 云同步」→ 功能卡里的**「账本同步（实验）」**：

- 点「立即同步」：先把本机改过的流水**上传**，再把云端比本机新的**下载**回来；
- 每条流水按「最后修改时间」取舍（后改的赢），删除也会同步（墓碑）；
- 页面显示**上次同步时间**和「上行 / 下行 / 跳过」三个计数，同步结果一目了然。

**这是第一版，请按「实验功能」对待**：

- **只有手动触发** —— 不会自动同步，冷启动 / 回前台 / 记完账都不会自己跑；
- **没有冲突提示界面**：同一笔在两边都改过时，静默按「后改的赢」处理；
- **不合并设置**：主题、首页布局、账本切换不跟着同步；
- 两台手机**同时新建**同一笔真实交易，可能各存一条；
- 手机时间不准会影响「谁更晚」的判断。

## 三、界面收口

- **设置页**：原来三张卡（界面外观 / 首页布局 / 云同步）合并成**一张卡三行**，去掉了长解释，只留一行脚注；
- **云同步页**：重排成**三块**（账号 / 功能 / 账号操作），删掉了分区标题和四段长说明，按钮收到行尾；
- **分类管理**：新建分类弹层、图标弹层、颜色选择、确认框统一圆角与行高，两个选择弹层补了抓手和标题，选中边框由 2px 收到 1px。

## 四、装哪个包

| 你的手机 | 下哪个 |
|---|---|
| 绝大多数近几年的 Android（arm64） | **arm64-v8a** |
| 很老的 32 位机器 | armeabi-v7a |
| 模拟器 / x86 平板 | x86_64 |

三个包**同一把签名**，可直接覆盖安装 v0.8.7，账本数据保留。
覆盖安装后「我的」页角标应显示 **v0.8.8**。

## 五、已知问题

- 账本同步没有自动触发、没有冲突提示、不合并设置（见上）；
- 「月份选择」页还不能跟手退场；
- 云备份（手动上传 / 换机恢复）与上一版一致，一次只覆盖**当前账本**。
