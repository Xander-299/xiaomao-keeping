# v0.8.5 发布说明

**发布时间**：2026-11-13 · **版本** `0.8.5+2005` · 三个 ABI 包（arm64-v8a / armeabi-v7a / x86_64）

一个小版本，只做一件用户可见的事：**外观设置从两个入口收成一处**。

---

## 设置里只剩一张「界面外观」

以前是两张卡片、两个子页：

```
外观模式   ›
主题色     ›
```

现在是一张卡片，**副标题直接告诉你当前是什么**：

```
界面外观
浅色 · 琥珀 主题色      ›
```

点进去是同一页的两段：

- **外观模式** —— 浅色 / 深色 / 跟随系统
- **主题色** —— 琥珀 / 森绿 / 黛蓝 / 藕粉 / 墨紫（琥珀仍排第一）

改完返回，卡片副标题立刻跟着变。

> 默认值不变：**浅色 + 琥珀**。

## 顺带修的两处工具链问题

不影响你用 App，但影响出包与验收的可靠性，记在这里以免下次再踩：

1. **WSL 里 `dart analyze` 突然报几千条错误**——不是代码坏了，是 Windows 侧 `flutter.bat pub get`
   把 `.dart_tool/package_config.json` 的包路径改成了 `C:/…`，WSL 读不到。新增
   `tool/fix_package_config.py`（别名 `fx-pkgcfg`）一键改回，并逐包校验目录是否存在。
2. **装机脚本在构建失败时会退回旧包**——曾差点把 `x86_64` 的包推到 arm64 真机。现在只认
   「本次构建新产出、且与模式匹配」的 APK，并校验 ABI；要复用旧包必须显式 `-NoBuild`。

## 装哪个包

| 你的手机 | 下哪个 |
|---|---|
| 绝大多数近几年的 Android（arm64） | **arm64-v8a** |
| 很老的 32 位机器 | armeabi-v7a |
| 模拟器 / x86 平板 | x86_64 |

三个包**同一把签名**，可直接覆盖安装旧版本，账本数据保留。
