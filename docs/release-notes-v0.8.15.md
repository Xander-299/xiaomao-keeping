# v0.8.15 发布说明

**发布时间**：2026-11-21 · **版本** `0.8.15+2015` · 三个 ABI 包（arm64-v8a / armeabi-v7a / x86_64）

这一版主角是**首页那个聊天框**：现在能顺着上一句接着问，也认更多日常说法。
另外顺手清了几个内部结构债（对使用者零影响）。

---

## 一、聊天框能接着问了

以前每句都得把时间说全（「这个月花了多少」），现在可以只补你要问的部分：

```text
你：这个月花了多少
它：本月支出 ¥2,260.50 …

你：那餐饮呢          ← 自动沿用「这个月」
它：2026年10月 · 餐饮 ¥1,280.50 …

你：大额的呢
你：比上个月呢
```

- 继承的只是**时间区间**：分类、商户这些必须由你这句说出来（不会把两个类别悄悄加在一起）；
- 中间穿插一句它答不上来的（「帮我写首诗」），之前的上下文**不会丢**；
- 每一句回答仍然会写明「查的是哪段时间」，数字对不上能一眼看出来。

## 二、多了几种说法

| 你可能会说 | 现在能答 |
|---|---|
| 昨天 / 前天 / 今天花了多少 | ✅ 按自然日 |
| 这周 / 上周 / 上上周花了多少 | ✅ 周一起算 |
| 最近三周花了多少 | ✅ 含本周在内往前三周 |
| 星巴克花了多少 | ✅ 按备注找：合计 + 笔数 + 最近一笔 |

商户查询靠**备注里的文字**匹配（自动记账会把通知原文写进备注），所以「星巴克」「瑞幸」这类
写在备注里的店名都能查；查不到会直接说「没有备注里带 XX 的支出」，不会编一个数。

## 三、内部清理（看不到，但会少踩坑）

- 账号相关的代码拆成「键约定 / 模型」两处；邮箱收成一个值对象，归一化只剩一条路
  （大小写写错导致整本账看不见那类问题，从结构上没了）；
- 切号流程改成显式步骤表，并修掉一个偶发失败：冷启动立刻切号时，开关状态读早了一步，
  可能在「恢复备份」环节被误判成「用户关了云同步」；
- `SavedAccount` 的时间字段换成 `DateTime`（落盘格式不变，老数据照读）。

## 四、关于「接本地 AI 模型」

评估过了，这版**没有**引入模型：1B 级量化模型会把安装包从 ~40 MB 抬到 **0.8–1.1 GB**，
首答 3.5–5 秒、常驻内存近 1 GB，而且基准里明确记录「模型算数会错」。
本版这些能力用规则实现，数字由业务代码算，**不会编**。
将来若真要「AI 味的措辞」，会做成**可选下载**（不进安装包），并且数字仍由代码算死。

## 五、数据与兼容

- 无数据库结构变化（仍 schema v7）；
- 三个包同一把签名，可直接覆盖安装 v0.8.14，数据保留；
- 覆盖安装后「我的」页角标应显示 **v0.8.15**。

## 六、装哪个包

| 你的手机 | 下哪个 |
|---|---|
| 绝大多数近几年的 Android（arm64） | **arm64-v8a** |
| 很老的 32 位机器 | armeabi-v7a |
| 模拟器 / x86 平板 | x86_64 |

校验下载完整性：对照 `SHA256SUMS.txt`；签名指纹与自证方式见 `VERIFY.md`。
